# 01. Первая лаба: 2 ПК + коммутатор

## Задача

Собрать простейшую сеть: 2 ПК через коммутатор. Настроить IP.
Проверить связность через ping. Посмотреть в Simulation Mode,
как пакет идёт по сети и как работает ARP.

## Что понадобилось

- **Cisco Packet Tracer** (любая версия)
- **Устройства:** 2 PC, 1 Switch (2960-24TT)
- **Время:** ~15 минут

## Топология

PC0 ── Switch0 ── PC1
(2960-24TT)

- PC0 → Switch0 (Fa0/1)
- PC1 → Switch0 (Fa0/2)
- Соединения: **Copper Straight-Through**

## Настройки

| Устройство | 	IP   | Маска |
|------------|-------|-------|
| PC0 | 192.168.1.10 | 255.255.255.0 |
| PC1 | 192.168.1.20 | 255.255.255.0 |

**Шлюз не нужен** — одна сеть, нет выхода за пределы.

## Ход работы

1. Создал топологию: 2 PC + Switch.
2. Соединил прямыми кабелями (Copper Straight-Through).
3. Настроил IP на PC0: `192.168.1.10/24`.
4. Настроил IP на PC1: `192.168.1.20/24`.
5. Проверил ping с PC0 на PC1 — работает, 0% потерь.
6. Открыл Simulation Mode — увидел, как пакет идёт от PC0 к PC1.

## Команды / настройки

**На PC0:**
- Desktop → IP Configuration → Static
- IP: 192.168.1.10
- Mask: 255.255.255.0

**На PC1:**
- Desktop → IP Configuration → Static
- IP: 192.168.1.20
- Mask: 255.255.255.0

**Проверка на PC0:**
ping 192.168.1.20


## Результат

- Ping PC0 → PC1: **4 пакета, 0% потерь, TTL=128**.
- Simulation Mode: видно путь пакета PC0 → Switch → PC1.
- ARP-запрос от PC0: «Кто такой 192.168.1.20?» — broadcast.
- Ответ PC1 с MAC-адресом.
- Только после ARP — ICMP-пакет (ping).

## Что увидел в Simulation Mode

- **ARP-запрос** — broadcast от PC0 («кто такой 192.168.1.20»).
- **ARP-ответ** — от PC1 с MAC-адресом.
- **ICMP-пакет** (ping) — только после ARP.
- **Коммутатор работает на уровне 2** — читает MAC, IP не понимает.
- **PC работает на всех 7 уровнях OSI** — данные проходят инкапсуляцию и декапсуляцию.

## Грабли

- Кабели должны быть **прямые (Copper Straight-Through)**, не кроссовер.
- При первом ping есть задержка — ARP должен разрешить MAC.
- TTL=128 — начальный TTL Windows.

## Что запомнить

- **Коммутатор** — устройство уровня 2 (канальный), работает с MAC-адресами.
- **Для отправки IP-пакета нужен MAC** — его даёт ARP.
- **ARP-запрос идёт broadcast** — всем в сегменте.
- **TTL=128** — стандарт для Windows. Уменьшается на роутерах.
- **Simulation Mode** — визуализация уровней OSI.
- **Прямой кабель** — для PC ↔ Switch, Switch ↔ Router.
- **Кроссовер** — для PC ↔ PC, Switch ↔ Switch, Router ↔ Router (в современном оборудовании автоопределение, но в PT — важно).
