# 02. VLAN: сегментация сети

## Задача

Собрать сеть из 4 ПК на одном коммутаторе, разделить на 2 VLAN
(Продажи и Бухгалтерия). Проверить изоляцию: ПК в одной VLAN видят
друг друга, ПК в разных VLAN — нет.

## Что понадобилось

- **Cisco Packet Tracer**
- **Устройства:** 4 PC, 1 Switch (2960-24TT)
- **Время:** ~20 минут

## Топология

PC0 ─┐
PC1 ─┼── Switch0 (2960-24TT)
PC2 ─┤
PC3 ─┘


**Порты коммутатора:**
- Fa0/1 → PC0 (VLAN 10)
- Fa0/2 → PC1 (VLAN 10)
- Fa0/3 → PC2 (VLAN 20)
- Fa0/4 → PC3 (VLAN 20)

## Настройки ПК

| ПК  | IP            | Маска         | VLAN |
| --- | ------------- | ------------- | ---- |
| PC0 | 192.168.10.10 | 255.255.255.0 | 10   |
| PC1 | 192.168.10.20 | 255.255.255.0 | 10   |
| PC2 | 192.168.20.10 | 255.255.255.0 | 20   |
| PC3 | 192.168.20.20 | 255.255.255.0 | 20   |

**Шлюз не нужен** — проверяем только L2-связность внутри VLAN.

**Почему разные подсети:** одна VLAN = одна подсеть. Это стандарт.

## Ход работы

1. Собрал топологию: 4 PC + Switch.
2. Настроил IP на всех ПК (разные подсети для VLAN 10 и VLAN 20).
3. Зашёл в CLI коммутатора.
4. Создал VLAN 10 (Sales) и VLAN 20 (Accounting).
5. Назначил порты Fa0/1, Fa0/2 в VLAN 10.
6. Назначил порты Fa0/3, Fa0/4 в VLAN 20.
7. Проверил `show vlan brief` — порты привязаны правильно.
8. Проверил ping PC0 → PC1 — работает (одна VLAN).
9. Проверил ping PC0 → PC2 — timeout (разные VLAN).

## Команды / настройки

### На коммутаторе (CLI)
```
enable
configure terminal

! Создаём VLAN
vlan 10
name Sales
exit

vlan 20
name Accounting
exit

! Назначаем порты
interface fa0/1
switchport mode access
switchport access vlan 10
exit

interface fa0/2
switchport mode access
switchport access vlan 10
exit

interface fa0/3
switchport mode access
switchport access vlan 20
exit

interface fa0/4
switchport mode access
switchport access vlan 20
exit

exit
write memory
```

### Проверка на коммутаторе

`show vlan brief`


Ожидаемый вывод:
```
VLAN Name Status Ports

1 default active Fa0/5-24, Gig0/1, Gig0/2
10 Sales active Fa0/1, Fa0/2
20 Accounting active Fa0/3, Fa0/4
```


### Проверка с ПК

**PC0 → PC1 (одна VLAN):**
`ping 192.168.10.20`

Результат: **4 пакета, 0% потерь** ✅

**PC0 → PC2 (разные VLAN):**
`ping 192.168.20.10`
Результат: **Request timed out, 100% потерь** ❌

## Результат

| Проверка                 | Результат                                      |
| ------------------------ | ---------------------------------------------- |
| PC0 → PC1 (VLAN 10)      | Ping OK, 0% потерь                             |
| PC2 → PC3 (VLAN 20)      | Ping OK, 0% потерь                             |
| PC0 → PC2 (VLAN 10 → 20) | Timeout, 100% потерь                           |
| `show vlan brief`        | VLAN 10 (Fa0/1, Fa0/2), VLAN 20 (Fa0/3, Fa0/4) |

**VLAN изолирует трафик на уровне 2.** PC0 и PC2 в одной физической сети
(один коммутатор), но в разных VLAN — не видят друг друга.

## Грабли

- **Разные VLAN = разные подсети.** Если бы PC0 и PC2 были в одной подсети,
  ping всё равно не прошёл бы из-за VLAN, но это сбивает с толку при проверке.
- **Порты по умолчанию — в VLAN 1.** Если не назначить порт в VLAN 10/20,
  он останется в VLAN 1 и будет видеть все остальные порты VLAN 1.
- **`switchport mode access`** — обязательно для портов к ПК. Без этого
  порт может работать в другом режиме.
- **`show vlan brief`** — главная команда для проверки VLAN.

## Что запомнить

- **VLAN** — логическое разделение одного физического коммутатора на
  несколько независимых сетей.
- **VLAN — уровень 2.** Коммутатор не пропускает кадры между VLAN.
- **Одна VLAN = одна подсеть** (стандарт).
- **Access-порт** — порт одной VLAN, для конечного устройства.
- **Trunk-порт** — порт нескольких VLAN, между коммутаторами/роутерами.
- **`show vlan brief`** — просмотр VLAN на коммутаторе.
- **Между VLAN нужен роутер (L3)** — коммутатор L2 не справится.
- **TTL не меняется** — трафик не проходит через роутер.
