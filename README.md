# my-sysadmin-notes
Учебный путь системного администратора: Windows Server + AD, сети, Linux, БД, скриптинг.
Теория, практика и разборы собеседований в одном месте.

## Что это

Личный учебный репозиторий. Здесь я собираю всё, что учу по пути к позиции DevOps-инженера:
теорию, практические лабы в облаке и разборы вопросов с собеседований.

## Зачем

- Не терять знания: всё структурировано по темам
- Видеть прогресс: таблица ниже + история коммитов
- Иметь портфолио-доказательство: не «я учил AD», а «вот конспект, вот лаба с командами, вот разбор ошибок»

## Что уже знаю (база)

- **Linux:** команды, права, процессы, логи, systemd
- **Docker:** Dockerfile, сборка, compose
- **CI/CD:** GitLab CI, GitHub Actions
- **Bash/Python:** 12+ скриптов
- **Zabbix:** разворачивал, настраивал триггеры
- **Nginx:** reverse proxy

## Что подтягиваю

1. **Windows Server + Active Directory** — GPO, DNS, DHCP, пользователи
2. **Сети** — OSI, TCP/IP, VLAN, маршрутизация, VPN, NAT, Firewall
3. **Linux глубже** — LVM, RAID, systemd
4. **Базы данных** — SQL, PostgreSQL, бэкапы
5. **Скриптинг** — Bash/Python закрепить

## Формат разделов

**`README.md` темы** — теория:
1. Зачем это нужно
2. Ключевые понятия — простыми словами
3. Как это устроено
4. Частые вопросы на собесе
5. Что важно не путать

**`practice/XX-*.md`** — практика:
1. Задача
2. Что понадобилось (окружение, ресурсы)
3. Ход работы — шаги своими словами
4. Команды / настройки — что реально вводил
5. Результат
6. Грабли — где споткнулся, как решил
