# my-sysadmin-notes
Учебный путь системного администратора: Windows Server + AD, сети, Linux, БД, скриптинг.
Теория, практика и разборы собеседований в одном месте.

## Что это

Личный учебный репозиторий. Здесь я собираю всё, что учу по пути к позиции DevOps-инженера:
теорию, практические лабы в облаке и разборы вопросов с собеседований.

## Зачем

- Не терять знания: всё структурировано по темам
- Видеть прогресс: таблица ниже + история коммитов
- Иметь портфолио-доказательство: не «я учил AD», а «вот конспект, вот лаба с командами, вот разбор ошибок»
